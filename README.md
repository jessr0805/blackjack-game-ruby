# Blackjack Game (RUBY)

A Ruby-based Blackjack game for people who want to play Blackjack, test their luck, or check out what basic Ruby code looks like.

## Cool Features

* **52-Card Deck**
* **Player Hit or Stand**
* **Dealer Automatically Draws to 17**
* **Player and Dealer Bust Detection**
* **Ace Scoring**
* **Win, Lose, and Tie Detection**

## How to Run It

Ensure Ruby is installed
If it isn't visit the
[Official Ruby Installer Link](https://www.ruby-lang.org/en/downloads/)

To run the game directly in the terminal,

* Clone the repository
* Navigate to the repository in your terminal
* Run

  ```bash
  ruby main.rb
  ```
